Judgment

Method

Two modes. One standard.

Launch

Used only when the files are in hand, the host is real, and the public URL can be verified. Then she makes the smallest high-impact changes and returns a single live link.

Elegant fallback

If anything required is missing, she does not pretend. She names the blocker, what is absent, the fastest next step, and the strongest deploy-ready artifact still possible.
